# WJ-793: Import now shows the GitHub run's progress

**What.** Sources → Import shows a live progress panel when an import runs on the GitHub collection runner. It updates every 5 s while shown.
- Steps: Sent to GitHub → Started → (Set up waiting sources) → Collect sources → Refresh Find → Done.
- A progress bar.
- Each source as it is collected (listings found, or why it failed).
- Each module's Find refresh with its count.
- A link to the run on GitHub.

Import now stays off, showing "Importing…", from the press until the run's last step. Scheduled runs show the same way.

**Why.** Owner, 2026-11-07: "i clicked on import now, but doesnt show any progress, the button is again available to press … show progress and whats completed". The press hands the work to GitHub, so the site had no record of it until the runner wrote one. With nothing waiting to set up, the runner never wrote one at all.

**How.**
- `server/gateway/liveRun.ts` adds a small platform-tenant document, `wj.liverun`.
  - The Import route records the press after GitHub accepts it.
  - `runner.ts` records each step through a `LiveRunTracker`: writes go out one at a time, the last state always lands, and a failed write never fails a collection.
- The gateway's `collectDue` takes an optional `onProgress` (due, start, done per source).
- `refreshGatewayListings` takes an optional `onModule`.
- The route refuses a second press while one is waiting or running.
- A press that GitHub doesn't start within 10 min, or a run silent for 20 min, is shown as such, and the button comes back.

**Notes.** No secret is stored; only source names, counts and the run's URL. Tests: `liveRun.test.ts`.

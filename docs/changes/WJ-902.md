- **What** (second UI only; the first UI is unchanged):
  - **The + is in the top bar**, beside the network icon (`chrome/CreateButton.tsx`). One press opens the kind's new-entry page (Post a job, Host an event…) with no menu. On Network it starts a post (on Messages, a new message). A kind with no entry of its own shows no +.

  - **Find's pills are slimmer:** Refine, the field pills and the round Search button are 36px (were 44px), with an invisible margin keeping a 44px tap area. Sort is 32px.

# WJ-614 · Co-founders · DONE

**What:** In a Co-founders connection, once interest is mutual and the other person's name shows, a "View network profile" link appears beside the name (and beside each founder's name on a team) when that person is on the WonderWorks Network and lets you see them. Before mutual interest nothing changes and no link shows.
**Why:** owner, 2026-11-20 (through the shared-layer session): the new Network "seamlessly connects with all the modules as much as possible".
**Notes:** Privacy: the link is resolved on the server (`server/network/links.ts::networkIdFor` / `networkIdsFor`) only where the module already shows the name (mutual, talking or building), and only the Network's public id reaches the browser, never an account id. The Network itself decides who may be linked (members only, not blocked, findable). A passed connection hides the name again and the link with it. Tiers, blocks and connections are unchanged. Tests: `server/cofounders/networkLinks.test.ts` (absent before mutual and the Network isn't even asked, present after, no account id in the response, absent when the Network offers none or after a pass, teams both ways). Help updated.

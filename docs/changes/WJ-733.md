# WJ-733 · Events & Social · DONE

**What:** TheSportsDB fixtures (Indian Super League, IPL) now name their league as the organiser and send the league's own badge as the organiser logo hint (`companyLogo`), so the organiser's logo shows with the fixture (through the shared company directory, WJ-763). A series without a badge ("One Day International Series") still names no organiser.
**Why:** Shared-layer session, 2026-11-06: once #678 merged, map any Events source that gives an organiser's logo. I surveyed all of them against real responses; this is the only one that does.
**Notes:** The badge is accepted only as an https URL on thesportsdb.com (the shared layer separately refuses private addresses and non-bitmaps). Not mapped, and why: Devpost (only a hackathon thumbnail, no organiser site; its URL is a devpost.com subdomain, so no `companyDomain`), HackerEarth (thumbnail, no organiser), Helsinki (provider name and event images), Devfolio (hackathon logo, no organiser name), Hasgeek and Linux Foundation (organiser name only, no logo), OpenAgenda (never run with a key). No security change; tests in `theSportsDb.test.ts`.

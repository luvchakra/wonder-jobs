# WJ-820: Network feed: report only what you could be shown; an author never sees a report's effect; a fixed order for same-moment rows

- **What:**
  - Reporting a post is refused (as "not available") unless the reporter could be shown it: a connection's update, or a post addressed to everyone by an author anyone may find.
  - A post hidden by reports stays in its author's own feed, so nothing tells them it was reported.
  - Messages, conversations and feed items written in the same millisecond now come out in one fixed order (time, then id).
- **Why:** Three observations from the E2E and security session (2026-11-21). With a leaked id, three accounts could have hidden a post none of them was ever shown. An author could notice a report when their post left their own feed. A message-order test failed about one run in four.
- **Notes:** `server/network/social.ts` only. Tests in `server/network/social.test.ts`.

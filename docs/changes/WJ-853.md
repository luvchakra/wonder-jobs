# WJ-853: Network mode on phones

- **What:**
  - The phone's bottom bar holds four places again (Find, Saved, the module's Pipeline tab, You).
  - Network is a raised round gradient button at the bottom right, right under the +, where the ⋯ menu button was. The ⋯ button is gone: help, account and sign-out are on the avatar.
  - Tapping Network opens network mode: on every `/app/network` page the bottom bar and the Network button are gone, and the + sits at the screen's foot. `:root[data-network-mode]` sets `--wj-mobile-nav-h` to the safe area only, so toasts and action bars drop with it.
  - In network mode, an icon right of the avatar in the top bar (the current module's own tinted icon, with a small back mark) leaves network mode. It returns to the last app page opened outside Network in this tab (`nav.ts::rememberAppPath`/`appReturnPath`, sessionStorage), or to the module's first place.
- **Why:** Owner request (2026-11-22): "move the network icon below + icon. once the network icon is clicked, hide the bottom bar completely. once in network mode, add an icon at green position in top navbar right of avtar. this icon should take user back to original app experience, taking user out of network mode."
- **Notes:**
  - Phones only. From a tablet up, the sidebar still lists Network and the modules.
  - The + stays in network mode, so New post and, on Messages, New message keep working.
  - Changed files: `wonderworks/chrome/MobileNav.tsx`, `TopBar.tsx`, `nav.ts`, `store/ui.ts` (the unused "fab" menu mode is removed) and `globals.css`.
  - E2E: GJ-008 is updated and GJ-008b added (network mode and the way back).

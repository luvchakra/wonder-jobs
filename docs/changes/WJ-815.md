# WJ-815 · WorksLake gateway · DONE

**What:** WonderArk can read WorksLake's business data. The gateway has a prospect data API (`/v1/prospects/search`, `/v1/prospects/sources`) that serves a new `businesses` dataset (and an empty `channels` one) to a key with prospect scopes, with every WonderArk business metered by a monthly allowance. Sources → Import has a new **Prospect data** card: the switch that lets WonderArk hold a key, Issue WonderArk key (shown once), the stored sources with their row counts, the allowance, and this month's use per business. The five OpenStreetMap services sources now also feed `businesses`, with each business's own published phone, email and website where the map states them. Talent & Services reads exactly what it read before.
**Why:** Owner, 2026-11-11 (`docs/PROSPECT_DATA_API.md`, packages A1 and A2): "WonderArk may read WorksLake"; "All data work happens in WonderWorks".
**Notes:**
- Separation: `businesses` and `channels` are not modules. No module route, module list, admin module card or the compatibility route reads them, and a prospect key gets 403 on every module route. A key holds module scopes or prospect scopes, never both.
- Organisations only: a source feeds `businesses` only if it is a source of public business or company listings. No person is stored; the usage ledger holds an opaque tenant id, the route, counts and paid units, never what was searched or found.
- Outside use: only the five `osm-services-*` sources are marked for it (owner approved, 2026-11-11). Houzz, WedMeGood and the therapists sources are not bound. A registered source takes its file's outside-use flag, dataset binding and evidence on the next collection or delivery (audited as `source.reconciled`).
- No schema change: dataset rows live in `gateway_listings` like any listing, found by tokens in `search_text`.
- Differences from the spec, written into `docs/PROSPECT_DATA_API.md` ("Build notes"): `provenance` is keyed by field; other sources of a merged record are listed at `source.alsoListedBy`; a filter the stored data cannot answer is named in `metadata.ignoredFilters`; a search reads at most 1,000 rows before merging (`metadata.capped`); `quota.resetAt` says when the allowance renews.
- Owner steps (all on Sources → Import as decisions): turn the switch on and issue the key, set it in WonderArk's Vercel project, and run the OpenStreetMap collection once to fill the dataset today.
- Tests: `apps/data-gateway/test/prospects.test.mjs` (scope isolation both ways, tenant header, allowance per tenant, filters, paging, merging duplicates, the definition sync, OpenAPI) and `apps/web/src/server/gateway/prospects.test.ts` (the hosted store, the admin card, key issue and revoke).

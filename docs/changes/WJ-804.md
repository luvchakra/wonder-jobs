# WJ-804: Visual polish pass (no functional change)

**What.** A styling-only pass over the shared layer, so every module and the admin pick it up. Nothing about what the app does changes.

- **Depth:** shadows are layered (a tight contact shadow plus a soft tinted one). Cards lift and take a brand-tinted border on hover; on touch screens they never stay lifted.
- **Buttons:** filled buttons get a lit top edge and a shorter, crisper brand glow, and rise a pixel on hover. Outline buttons get a hairline shadow.
- **Result cards:** cards in a row share one height, so every footer (source, Share, Save) sits on the same line and the summary fills the spare room. The first nine cards fade up in sequence.
- **Form controls:** checkboxes and radios are drawn in the brand's shape and colour in every browser. Inputs get a hairline shadow and a hover border. The text cursor and native ranges use the brand colour.
- **Dialogs:** rise and fade in, with the backdrop fading behind them and a hairline ring.
- **Navigation:** the active sidebar item has a hairline brand ring. The phone's bottom bar is frosted with a soft shadow above it.
- **Details:** thin themed scrollbars, balanced heading line breaks (h1, h2), no lone last word in paragraphs, a softer loading shimmer, a halo on empty-state icons, hairline rings on badges, a frosted toast.

**Why.** Owner, 2026-11-11: make it look like a polished, production-grade application; "superficial changes and not any functional level changes".

**How.** Tokens and base rules in `globals.css`, plus class changes in the shared components (`Button`, `Input`, `Badge`, `Modal`, `States`, `Tabs`, `Toast`), the chrome (`Sidebar`, `MobileNav`) and `find/parts.tsx` (`ResultsGrid`, `ResultCard`). Every animation is switched off under `prefers-reduced-motion`.

**Checked.** Typecheck, lint and the shared-layer, common-component and Jobs tests (90). Looked at Jobs Find (desktop and phone), Refine, Internships Find (phone) and Job sources locally. Admin pages and the landing page were not looked at.

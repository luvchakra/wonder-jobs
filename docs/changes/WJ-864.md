# WJ-864: Messages keeps the mode the member is in

- **What:**
  - Messages lives at `/app/network/messages`, so opening it from a module's top bar switched to network mode: the bottom bar went and the way back appeared. Messages now keeps whichever mode the member came from. From a module, the module's chrome and bottom bar stay. From My network, network mode stays.
  - Network's other pages are always network mode, and module pages never are.
  - On Messages, the "← My network" link shows only in network mode.
- **Why:** Owner report (2026-11-23): "clicking on messages icon in non network mode is taking it to network mode, that's not correct, ensure it remains in the same mode".
- **Notes:**
  - New `wonderworks/chrome/networkMode.ts`: `networkModeFor` (unit-tested) and `useNetworkMode`. The last mode is held in memory only, so a reload of Messages opens in the app.
  - `TopBar.tsx`, `MobileNav.tsx` and the Messages page use it.
  - Help is updated (Network).
  - E2E GJ-008c added.
- **PR:** see the squash commit.

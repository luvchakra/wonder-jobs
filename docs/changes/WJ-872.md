# WJ-872: Workday career sites in WorksLake, with 20 insurers, reinsurers and brokers

- **What:**
  - **New ATS platform `workday` in WorksLake core.** A board's slug is `<tenant>.<wdN>.<site>`.
    - Add Source detects a `*.myworkdayjobs.com` URL (the site page, a job page with a locale, or the `/wday/cxs/` endpoint), which used to show "no connector yet".
    - The connector (`server/jobslake/ats.ts`) POSTs the search words to the site's public jobs endpoint, 20 a page, up to the depth's cap. It reads the first few postings' details for the description, every location and the real posting date.
    - From the list alone, "Posted N Days Ago" becomes a date and "30+ Days Ago" gives none.
    - A site that can't be read is an error, not an empty list.
  - **Built-in source "Workday career sites" (Jobs)** with 20 sites the Jobs session checked live on 2026-11-26 (`WORKDAY_BOARDS` in `server/jobs/providers.ts`):
    - reinsurers: Everest, RGA, MS Reinsurance, MS Amlin, AXIS, Arch, Markel, Hiscox;
    - insurers: AIG, Travelers, The Hartford, Allstate, Corebridge, Berkshire Hathaway Homestate, Manulife, Prudential plc, Swiss Life International;
    - brokers: Marsh McLennan, Brown & Brown, HUB International.
  - **Help and `docs/EXTERNAL_DATA_SOURCES.md`** list them, with "terms pending: Workday tenant terms".
  - **The live smoke test can run again:** `src/testing/isolate.ts` stripped `JOBSLAKE_LIVE` as if it were a credential, so `JOBSLAKE_LIVE=1 npx vitest run live.smoke` always skipped. It now includes a Workday site.
- **Why:** Owner (2026-11-26): "check why it's not able to look for job in insurance domain". The keyless sources were almost all tech, while most large insurers, reinsurers and brokers post on Workday.
- **Notes:**
  - Checked live: an "underwriter" search found Travelers 40, Hiscox 7, RGA 4 and Marsh McLennan 10 jobs, each with a real date, its locations and a description, in 1–3.5 s a site.
  - The source starts active, like the other built-in career-site sources, with its terms pending in `statusReason`.
  - Workday is read per search like the other ATS boards (WorksLake's search cache applies). A site gets at most 2 list calls and 6 detail calls in a normal search.
  - Workday sites are Jobs' only; Internships and Teaching can add their own later through the same board type.

# WJ-805: Jobs: a bolder, premium result card (a trial; one revert undoes it)

**What.** Jobs' result cards (Find, Saved and wherever the Jobs card shows) get a new look. The content and every control stay the same.

- **Card:** roomier, with a larger radius. On hover the border turns into the brand gradient and the card lifts with a purple-tinted shadow.
- **Match:** a ring that fills to the score in the fit's colour, with the number inside, in place of the green pill.
- **Facts:** place, work mode, job type and pay each get a small icon; pay is in bold. The dot separators are gone.
- **Skills:** squared, outlined chips.
- **Footer:** a hairline divides the source line, Share and Save from the body.
- **Apply:** a slightly larger pill with the brand glow.

**Why.** Owner, 2026-11-12: "go for bolder change for jobs screen, maker it more professional and premium. if i like the changes you can do the same for other modules, if not then revert it back."

**How.**
- `ResultCard` takes an optional `premium` flag and `find/parts.tsx` gains `FitRing`; `globals.css` gains `.wj-card-premium`. Other modules don't pass the flag, so they are unchanged.
- `modules/jobs/components/JobCard.tsx` passes `premium`, uses `FitRing` and adds the fact icons. Jobs' card is the Jobs module's file; this styling change was made from the shared-layer session at the owner's request.

**To undo.** Revert this PR. To roll out, pass `premium` from each module's card.

**Checked.** Typecheck, lint, tests. Looked at Jobs Find on desktop and phone locally.

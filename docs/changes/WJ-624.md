# WJ-624 · Buy, Sell & Rent, Network · DONE

**What:** In a Buy, Sell & Rent conversation, once the other person has shared their email, a "View network profile" link to their Network profile appears under it (only when they are on the Network and it lets you see them). Until they share, you see a first name only, as before.
**Why:** Shared-layer request (2026-11-21), from the owner (2026-11-20): Network "seamlessly connects with all the modules as much as possible".
**Notes:** The id is resolved on the server with `networkIdFor`/`networkIdsFor` (one batch call for the Deals list) and only the public network id reaches the browser, never an account id; it is set only when the counterpart has shared contact in that thread. The network helper itself returns nothing when either person isn't on the network, one blocked the other, or the person isn't findable by everyone. No new capability or external effect. Tests in `server/marketplace/marketplace.test.ts`: absent before sharing, present after (each side separately), no account ids in the payload, and none when not on the network, by-link-only or blocked.

# WJ-868: A community's own photo

- **What:**
  - **Changing it:** the owner, or a moderator with Settings, sets the community's photo by tapping its picture (the camera mark) or from ⋯ → Add a photo / Change photo. ⋯ → Remove photo brings the letter mark back.
  - **Preparing it:** the browser cuts it square from the middle, shrinks it to at most 512 px and redraws it as JPEG. The server checks it again (JPEG, PNG or WebP by its bytes, at most 1 MB) and removes any metadata.
  - **Where it shows:** wherever the community's mark does (`CommunityAvatar`): its page, lists, Discover, discussions. It also shows on its public page (`/c/<id>`) and in its link preview image.
- **Why:** Owner request (2026-11-23): "add option to change profile picture of community".
- **Notes:**
  - **Migration 0062:** `network_communities.photo_at`, and `network_community_photos` (one row per community, keyed by it, no person column; who changed it goes in the mod log).
  - **Routes:** `/api/network/communities/<id>/photo` (GET for anyone on the network; POST and DELETE for settings moderators), and the public `/c/<id>/photo` (public communities only).
  - **Caching:** the photo address carries when it changed, so a new one is fetched afresh.
  - **Before the migration:** setting a photo says "Communities aren't switched on yet".
- **Privacy:** a private community's photo is seen only on the network (as its name is), never on the open web.
- **Tests:** `communities.test.ts` ("a community's photo"): who may change it, metadata removed, network vs open web, removal. The network routes' sign-in check now covers the photo route. Checked at phone width: an upload, the header, the list, the public page and the preview image.
- **PR:** see the squash commit.

## Also in this PR: the "Posted" toast leads to the new post

- **What:**
  - After a post from the + (or Post to my network), the "Posted" toast has **View post**. It opens My network with the feed scrolled to the new post (`/app/network?post=<id>`), marked for a moment.
  - A post into a community shows **View discussion**, which opens the new discussion.
  - Any toast with a button now stays 10 seconds (was 4.5), and tapping the button closes it.
  - `publishPost` returns the new post's id.
- **Why:** Owner request (2026-11-23): "in the message show the link to directly go to the new post created. keep the toast for little longer so user gets time to click".

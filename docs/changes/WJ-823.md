# WJ-823 · WorksLake gateway · DONE

**What:** A WonderArk channel search now returns public outlets and gatherings: conferences from confs.tech as events and the Stack Exchange network's sites as forums from stored data (no key needed), and YouTube channels and podcasts when their keys are set. Gathering places (schools, colleges, coaching centres, gyms, clubs, community centres, coworking spaces) are a business search with the category group `gathering_places`. On Prospect data, a source the gateway fetches itself has a Test button before Activate.
**Why:** Package A6 of `docs/PROSPECT_DATA_API.md`: WonderArk needs to find where an offering's consumers already are.
**Notes:** Only confs.tech among the nine Events sources is bound, marked for outside use on the MIT licence quoted in its own file; the other eight are not, because their files do not allow it. Its Events rows are unchanged (tested). Stack Exchange sites is a new catalogue source, added paused; its API was tried once (three sites) to confirm the documented shape. Podcast Index, events and forums state no audience size, so only YouTube results carry one. No source was found for communities, newsletters or publications; Reddit is recorded as considered, and Facebook groups, Instagram, WhatsApp, Telegram and LinkedIn as out of reach (`docs/EXTERNAL_DATA_SOURCES.md` §14.1). Governance: a channel holds a public name, link, topics, language, country and stated audience only; no personal email or profile. Owner decisions: `prospects-solo-creators`, `prospects-event-channels`, `prospects-community-sources`. Tests: `apps/data-gateway/test/channels.test.mjs`, `apps/web/src/server/gateway/prospects.test.ts`.

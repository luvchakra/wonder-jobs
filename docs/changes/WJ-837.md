# WJ-837: Modules in communities: a topic module, listings in discussions, Post to a community

- **What:** Modules and their content fit into communities without changing how the network works.
  - **A community's topic:** an optional module (Jobs, Teaching, Events…), chosen when creating or editing it and shown as a chip. When browsing Communities from a module, Discover puts the communities about that module first.
  - **Listings in discussions:** a discussion can carry a listing from any module. It shows as the same rich card as the feed (picture, title, details, start of the description), and the discussion list shows the listing's module chip.
  - **Post to:** the post box (opened from +, from a listing card's post button, or from Share → My network) now offers **Post to: My network** or one of the member's communities.
    - Choosing a community adds a Title field, keeps the attached listing, and starts a discussion there.
    - Photos stay with feed posts.
    - On a community's own pages, + preselects that community.
    - People in no community see no change.
- **Why:** Owner request (2026-11-22): "integrate modules and it contents on community level. it should be seamless integration without changing much of networking experience, it should just fit in, not block the experience".
- **Notes:**
  - Migration `0059_community_modules.sql` adds `network_communities.module` and `network_threads.href` / `about` / `module`. It is additive. Until it is applied, communities and discussions without a topic or listing work as before.
  - Code: `domain/network/communities.ts` (`cleanAttached`), `server/network/communities.ts`, `components/network/PostSheet.tsx`, `community.tsx` (`ModuleChip`), and the community pages.
  - **Governance:** a discussion can carry only a public listing page; its module comes from the path, checked on the server, as for feed posts. Posting to a community is starting a discussion, so the community's membership checks and `network.post` apply.
  - Tests: `server/network/communities.test.ts` (topic, Discover order, attachment validation); the domain test is updated.

# WJ-907: Account menu: a link to install the browser helper

- **What:** the account menu (the avatar's menu, both UIs) has **Install browser helper**, between Analytics and Get Help.
  - Not installed in this browser: it opens the helper's Chrome Web Store listing in a new tab once there is one (`NEXT_PUBLIC_EXTENSION_STORE_URL`), else `/extension` (the download and its steps).
  - Installed: the row reads "Browser helper · Installed" and opens `/extension` (its version and updates).
  - It's an item of the account menu (`helper` in `domain/navigation/menus.ts`), so Admin → Settings → App menus can move or hide it.
- **Why:** Owner (2026-11-28): "for the extension, create quick link to install in menu".
- **Notes:** The check is the existing ping the helper answers on our own pages (`useExtensionInstalled`), run only while the menu is open. Nothing about what the helper fills or presses changes. Help updated.

# WJ-721 · Platform (shared) · DONE

**What:** Sources → Import: a source that failed 3 tries in a row, whether from Import now, a module's import or its own Try again, or that an admin dismissed, moves off its module's card into a new **Archived** section at the end of the page, grouped by module. Import now, the scheduled run and a module's import leave archived sources out. Each archived row keeps its buttons (Try again, Restore), and a success moves it back to the card. A live source whose last 3 collections failed is archived too; the gateway still retries it on its schedule.
**Why:** Owner, 2026-11-05: "the sources which are failing even after multiple tries and fixes, move them to an archived section at the end of the page".
**Notes:** Failed tries in a row come from the kept import runs plus a row's own tries, which are stored next to the runs in `wj.importruns` (`tries`) and capped. No security change.
**PR:** see the PR that adds this file.

# WJ-821: Network posts from the + in every module, about the listing on screen

- **What:**
  - **The + creates a network post**, in every module.
    - On a phone it opens "New post". Where the module also has its own new entry (post a job, host an event…), it first asks which: Post to your network, or that entry. On Network's pages it opens the post straight away.
    - From 768px, Network has a New post button at the top (tablets and desktops have no floating +).
  - **A post can carry a listing.** Pressed on a listing's page (a job, or any module's listing with a public page), the post sheet attaches that listing, and the × takes it off. Share → My network on any listing card or page opens the same sheet with that listing attached.
  - **Posts are marked with their module.** The feed shows each post's module and the attached listing as a link card.
  - **The "Share something with your network" box is gone** from the feed.
- **Why:** Owner request (2026-11-21): "design post mechanism for the network feature. creating post should be possible from various modules and related Artifacts. use the + icon to create new post. remove share something option".
- **Notes:**
  - Migration `0053_network_post_about.sql` adds `network_updates.about` (the attached listing's title). Until it is applied, posts are stored without the title and the link card reads "See the listing".
  - `wonderworks/chrome/postTarget.ts`: a listing page registers what is on screen (`usePostAbout`), only a public page (`/j/<id>`, `/s/<module>/<id>`). Wired in the shared `ListingPage` (every module) and Jobs' job page.
  - **Security / governance:**
    - A post's listing must be a public listing page, checked on the server; its module comes from the path.
    - A post's own module tag must be a plain module id.
    - Posting still goes through `network.post` and is audited without the words. The sheet shows what goes and to whom before Post.
  - Tests: `server/network/social.test.ts` (attachment validation, module from path, odd module ids dropped). A two-step walkthrough at phone width: + on a job page → Post to your network → the job attached → posted → shown in the feed with the job linked.

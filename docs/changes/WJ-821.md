# WJ-821 · WorksLake gateway · DONE

**What:** Every value that enrich fills now carries the date it was observed. Where the company directory holds no date for a fact, the date is when the company was last seen there, else the time of the lookup.
**Why:** WonderArk's client refuses an enrich answer in which a filled field has no date (the contract's example always has one), so a directory fact without a date would have turned the whole answer into "Unavailable".
**Notes:** None for security or governance. Test: `apps/data-gateway/test/prospects.test.mjs` (a fact given without a date still comes back with one).

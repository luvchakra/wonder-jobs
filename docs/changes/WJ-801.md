# WJ-801: Sources → Import: finished runs move to History

**What.**
- The top of Sources → Import now shows only what is under way: a runner run in progress or waiting to start, or one that stopped without finishing.
- Finished runs move to a new **History** section lower down. That section holds:
  - the last runner run's panel;
  - the last import's summary;
  - the Runs list.

**Why.** Owner, 2026-11-07: "show history in separate section below". Finished panels at the top looked like current activity.

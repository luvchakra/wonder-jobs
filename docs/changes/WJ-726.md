# WJ-726 · Platform (shared) · DONE

**What:** A collection or import call never runs past Vercel's 60 s for refreshing Find. The refresh starts a module only while time is left, and leaves the rest of the modules to the next call: the collection chain (`?refresh=`), or the import job (`refreshLeft`; the job finishes once every module is refreshed). Before, a run whose Find was stale refreshed all nine modules (up to 1,000 listings each) in the same call after collecting. It ran out of time (504), so nothing was recorded and nothing was handed on.
**Why:** Owner, 2026-11-05: "ensure all other sources are activated and running". A collection started after WJ-725 went live collected 3 sources, then failed with a 504.
**Notes:** `warm.ts::refreshGatewayListings(modules, now, deadline)` returns `remaining`, and `continueSetupJob` returns `more` for its hand-on. No security change.
**PR:** see the PR that adds this file.

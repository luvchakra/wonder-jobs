# WJ-799: Sources → Import: sources of one site no longer look duplicated

**What.** Rows in one module that share a name now say what sets each apart, for example "Houzz (houzz.in) · Architects" and "Houzz (houzz.in) · Interior designers and decorators". Before, ten Houzz rows all read "Houzz (houzz.in)".

**Why.** Owner, 2026-11-07: "why so many duplicate entries". They aren't duplicates: Houzz has one source per trade category, each with its own URL, but all ten share the attribution "Houzz (houzz.in)".

**How.**
- `importView.ts::distinctNames` runs on each module's rows.
- When names repeat, it adds the first part of the source's URL path that differs, or the catalogue file name for sources not added yet. Words every row starts with are dropped.
- The gateway overview now carries each source's URL path.

**Notes.** Houzz and WedMeGood still refuse our server (the "Houzz and WedMeGood" decision row). Test & activate fails for all ten until Houzz allows access.

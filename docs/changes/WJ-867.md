# WJ-867: A shared community's link previews with the WonderWorks logo and the community's mark

- **What:**
  - A public community's link (`/c/<id>`) now has a preview image (`app/c/[id]/opengraph-image.tsx`), and its card is the large-image kind (`summary_large_image`). Apps like WhatsApp, X, Slack and iMessage show it.
  - The image shows the WonderWorks mark and name, the community's own mark (its letter on its colour, the same as in the app), its name, and its member and discussion counts.
  - A private community's link shows a plain "A community on WonderWorks" card with nothing about it.
- **Why:** Owner request (2026-11-23), on a WhatsApp share: "show logo of WonderWorks and also community icon in the message".
- **Notes:**
  - The community's colour now comes from `domain/network/communities.ts::communityTone`, shared by the app's mark and the image.
  - The image is cached at the edge for a day (`s-maxage=86400`), so a link passed around doesn't redraw it each time, which keeps CPU low.
  - WhatsApp caches a link's preview, so a link already sent keeps its old card; new shares show the image.
  - Help is updated (Network).
- **PR:** see the squash commit.

# WJ-900: Second UI: Find before a search, skeletons while searching, and a title said once

- **What** (second UI only; the first UI is unchanged):
  - **Find before the first search** (every module on the shared Find; Jobs has its own): where there was only "Search for…", Find now shows what the browser already holds, as sections.
    - **Recent searches:** pills; a tap searches those words, as picking one under the box does.
    - **Saved:** a rail of the saved listings on the module's own card, with the count and "See all" to Saved.

  - Cards in a rail share its height.

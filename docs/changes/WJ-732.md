# WJ-732 · Events & Social · DONE

**What:** An online-only event reads "Online" once on its card, its page and its share text, not "Online · also online". "also online" stays for an event in a place that also streams. Devpost hackathons (place stated as "Online") were the case.
**Why:** Shared-layer session, 2026-11-06, a bug seen on the owner's phone ("Online · also online · PayPal" in an "ai hackathon" search; I can't verify who saw it).
**Notes:** Two fixes: `toOutsideEvent` reads a source's place that is only the word Online/Virtual/Remote as no place (so such an event is online only), and `outsidePlace`/`sharePlace` do the same for a listing already saved. A real place that merely contains the word ("Online Park, Pune") is still a place. Tests in `outside.test.ts` and `share.test.ts`. No security change.
**PR:** see the PR that adds this file.

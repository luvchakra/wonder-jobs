# WJ-818 · WorksLake gateway · DONE

**What:** The prospect data API gains three routes for WonderArk. **Enrich** fills one organisation's blanks from the cheapest source first: WorksLake's company directory (reported facts, then Wikidata), stored businesses with the same domain, then the organisation's own website (its home page and at most one contact or about page). **Contacts** returns the organisation's own published mailboxes and says that the people providers (Hunter, Apollo) need setup. **Suppress** records a removal request, after which that address or domain is never returned to any WonderArk business.
**Why:** Owner, 2026-11-11 (`docs/PROSPECT_DATA_API.md`, package A4): "fill an organisation's blanks from the cheapest source first, and find people only on request".
**Notes:**
- Open web: the site reader uses the gateway's own safe fetch (HTTPS only, public addresses only, the address pinned, no redirect to another host), reads robots.txt first and does not read a site that disallows it or whose robots.txt cannot be read, takes two pages at most within nine seconds, and returns plain text. A page's words are data.
- People: nothing about a person is stored or logged. A mailbox is returned only when it reads as the organisation's own (a role address, or one named like the site); a LinkedIn link only when it is a company page. The removal list holds keyed hashes only, up to 2,000; a full list refuses a new request (507) rather than dropping an old one.
- No paid provider is connected: enrich with `allowPaid` reports Apollo as needs setup, and contacts reports Hunter and Apollo as needs setup. No unit is spent.
- Free lookups (enrich, contacts) count against a WonderArk business's monthly free allowance, with searches.
- Terms pending, as owner decisions on Sources → Import: facts reported by job-data sources passed to WonderArk (`prospects-directory-facts`), and how a person asks to be removed (`prospects-removal-requests`).
- Stored rows gain a domain token, so enrich finds a stored business by its domain; rows collected before this get it on their next collection.
- Tests: `apps/data-gateway/test/prospects.test.mjs` (waterfall order and sources, private and metadata addresses refused, robots, two pages, plain text, no personal mailbox, suppression across tenants, nothing personal in state or logs), `apps/web/src/server/gateway/prospectHooks.test.ts`. The site reader was also run against one real business site.

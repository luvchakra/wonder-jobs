# WJ-840 · Tests · DONE

**What:** Tests only, nothing changes for users. Network's API routes (`/api/network/*`) and the job seeker's photo and résumé reads (`/api/hiring/[org]/talent/[tenant]/photo` and `/resume`) now have route-level security tests, and Network has a two-browser Playwright journey (`e2e/network.spec.ts`): both people join, one sends a connect request with a note, the other accepts, each lists the other, and a message one sends shows in the other's Messages.
**Why:** owner, 2026-11-21: "run e2e tests in parallel session, also include security related tests". These features merged on 2026-11-20/21 (WJ-810, WJ-811, WJ-812) with server-level tests only.
**Notes:** What the new tests hold in place. Network: every route is 401 signed out; someone not on the network can't browse, open, list or ask (409); a hidden part never leaves, a connections-only part only once connected; search can't find someone by a part the viewer can't see; the photo follows its own setting and is served sandboxed; a connection can be acted on only by its two people (404 for anyone else); a block hides both people on every route with the same answer as "never existed"; a request isn't sent until confirmed when the automation setting can't be read (`resolveCapability` fails closed); no response, answer or refusal, contains an account id or email. A test lists the route files under `/api/network`, so a new route fails it until it is added to the 401 list. Talent photo/résumé: 401 signed out, 403 for a role without `talent.search`, refused for other workspaces, 404 until the job seeker shares each one and again the moment they stop or leave. Messages: only between two connected people, never on a waiting request, not until confirmed when the setting can't be read, 404 for anyone else and for both once the connection ends, is blocked or the other leaves; a message carries no sender id. Updates: only connections', none from someone who turned sharing off, and a shared listing must be a listing's public page (`/j/<id>`, `/s/<module>/<id>`), nothing else. The Playwright journey runs on a local build only (migration 0051 isn't on production).

# WJ-879: Second UI: a polish pass (type, buttons, focus, empty states, loading)

- **What** (second UI only; the first UI is unchanged):
  - **Type:** four sizes (12, 14, 16, 20) and two weights (400, 600). The first UI's 32 in-between sizes land on the nearest of the four at each breakpoint; bold and extrabold become 600, medium becomes 400.
  - **Colour:** crisper neutrals (text `#0F0F0F`, secondary `#737373`, hairlines `#DBDBDB`) and a light grey fill (`#EFEFEF`).
  - **Buttons:** three kinds. Primary is the solid accent; secondary (the old outlined and tinted buttons) is a light grey fill with black text; ghost stays plain text. All are 600 weight and press in slightly (0.97).
  - **Focus:** a visible 2px accent ring on every link, button, tab and menu item for keyboard users.
  - **Red** is for counts that want attention: the bell's and Messages' badges were purple.
  - **Empty states:** one outline icon in a circle, a bold line, a grey line and a text button. The dashed box and tinted halo go.
  - **Loading:** a page still loading shows grey skeleton blocks in the page's shape in place of the centred brand loader. It's chosen in CSS, so it's right before the page hydrates.
  - **Sheets and dialogs:** 12px corners, and a handle at the top of a bottom sheet on a phone.
  - **Bottom bar:** the active place's icon is filled (Find's magnifier gets a heavier line: it has nothing to fill).
  - **Motion:** 200ms ease-out.
- **Why:** Owner (2026-11-28), on a second brief modelled on a minimal content-first app: "just take the inputs that make the ui look more professional and polished". The second UI's structure (header, module row, cards, floating bar) stays.
- **Not taken:**
  - Dark mode: 192 hard-coded colours in 32 files would show through, so it needs its own pass before it can follow the system setting.
  - The five-icon unlabelled tab bar, feed-style results, the highlights rail, the three-column square grid and the centred desktop column. They are structure, not polish.
  - The strict 4px spacing grid and 24px icons everywhere: they need each screen laid out again.
- **Notes:**
  - Counters under 11px (badges, the match ring's label) and the landing page's display sizes keep their size.
  - No behaviour change. `CLAUDE.md` records the second UI's type and button rules, and the shared layer's next id block (WJ-900–929).

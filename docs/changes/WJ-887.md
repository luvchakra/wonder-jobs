# WJ-887 · Jobs · DONE

**What:** Full Time's Search now runs as the profile that Looking for shows. That is the role picked under "Search as" or, if none is picked, the role the last search ran as. This holds after a reload or a return to the app.
- Coming back from Career Profile after a change (`?refresh=1`) searches again as that same role.
- A role that has since been deleted counts as My profile.

**Why:** Owner, 2026-11-26: "even though reinsurance is selected when i return to the app later, when i click on the search button, it search for different profile".
- The Looking for line showed the last run's role.
- Search (`runPlaces`) only looked at the page's "Search as" pick. That pick is cleared after every search and lost on reload, so Search ran as My profile, even without a reload.

**Notes:**
- `modules/jobs/searchAs.ts::fullTimeSearchAs` decides both what the pill shows and what Search runs as, so the two can't disagree.
- The pick isn't persisted on its own: what's shown comes from the last run, which is already persisted.
- Test: `searchAs.test.ts` covers reload, picked, My profile and deleted role.
- Checked at 390px. Search as Reinsurance, then reload: the pill still shows "Reinsurance · insurance operations". Pressing Search ran a new search as Reinsurance (two more role runs). On main, the same steps searched as My profile.
- Part Time is unchanged: it searches only typed words.
- No automation, AI or external-action change.

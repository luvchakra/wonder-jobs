# WJ-775 · Platform (shared) · DONE

**What:** The hosted gateway needs no environment variables of its own.
- **Admin token and cursor secret:** derived from `SECRET_ENCRYPTION_KEY` (`server/gateway/secrets.ts`).
- **WorksLake's API key for the gateway:** derived the same way, and registered in the gateway's key table by its digest the first time it's read (consumer `workslake`, read access to every module), exactly as `issueKey` stores keys.
- **Address and bridge switch:** the gateway's address defaults to the site itself, and WorksLake's gateway bridge is on whenever the gateway runs.
- **Variables removed:** `GATEWAY_ADMIN_TOKEN`, `GATEWAY_CURSOR_SECRET`, `WORKSLAKE_GATEWAY_API_KEY`, `WORKSLAKE_GATEWAY_URL` and `WORKSLAKE_GATEWAY_ENABLED` are no longer needed on the deployment, and the GitHub collection runner now needs only three secrets: `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`, `SECRET_ENCRYPTION_KEY`.

**Why:** Owner, 2026-11-06: "make all the changes you suggested regarding the environment variables", second of two PRs (WJ-774 moved email, AI, push and the runner token into Admin → Keys).

**Notes:**
- **Compatibility:** a variable the deployment sets still wins, so a deployment that sets them behaves exactly as before. `WORKSLAKE_GATEWAY_ENABLED=0` still turns the bridge off.
- **When it switches on:** a derived gateway turns on only with Supabase configured (its state lives there), so tests and local runs without Supabase stay off.
- **Security:** each value is an HMAC-SHA256 of the encryption key with its own label, so the values differ and none reveals the key. The site and the GitHub runner share the key, so they derive identical values. The derived API key is stored only as its SHA-256 digest; the tests check that the gateway's own `requireConsumer` and `checkScope` accept it.
- **Rotating `SECRET_ENCRYPTION_KEY`** already meant re-entering every admin key; it now also re-derives these (the new API key is registered automatically, and the old one can be revoked on the gateway's key list).
- **Module files touched:** `services/sources.ts` and `therapists/sources.ts`, one line each, now call `gatewayConfigured()` instead of reading the two variables.
- **Tests:** `server/gateway/secrets.test.ts`.

**PR:** see the PR that adds this file.

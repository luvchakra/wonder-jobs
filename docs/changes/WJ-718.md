# WJ-718 · Platform (shared) · DONE

**What:** Gateway sources take a per-module filter, `moduleFilter: { <module>: { field, match, negate? } }`: a source in several modules sends each item only to the modules whose filter it passes. `field` is `title`, `organization` or a mapped `attr.<field>`; `match` is a case-insensitive pattern (1–200 characters); `negate: true` keeps the items that don't match.
**Why:** Owner, 2026-11-05: "move PETA internship to Internships". Buddy4Study lists internships among its scholarships; the Scholarships session will give its entry `modules: ["scholarships","internships"]` and filter on its `oppurtunityType` field.
**Notes:** Validated in `validateSource` (module listed, field mapped, valid pattern); no filter keeps today's behaviour. Run reports count `filtered`. Tests: `apps/data-gateway/test/module-filter.test.mjs`.
**PR:** see the PR that adds this file.

# WJ-817 · WorksLake gateway · DONE

**What:** Prospect data gets its first bulk open-data source, Overture Maps Places for India: 30,000 real businesses (trades and field services first) with their own website or phone, read from Overture's monthly release on the GitHub runner and delivered to the app in batches. On Sources → Import → Prospect data the source has one button at a time: Add, then (after a collection) Activate, then Pause. A search can now ask for a trade by any of its names ("plumbing" finds plumbers from every source) and for a named group of categories (`categoryGroup`, e.g. `trades` or `gathering_places`).
**Why:** Owner, 2026-11-11 (`docs/PROSPECT_DATA_API.md`, package A5): "enough stored organisations in India that a stored search is useful without any paid call". OpenStreetMap's trades rarely state a phone or website; 97% of the Overture rows kept state a phone and all state a website.
**Notes:**
- Licences: read from the release itself. Only rows whose every source is CDLA Permissive 2.0, Apache 2.0 or CC0 are kept. Attribution wording is terms pending (owner decision `prospects-overture`).
- Organisations only: no chain branch, no listing named after an individual (Dr., Adv., Mr. …), at most two rows per organisation, and an email only when it reads as the organisation's own mailbox. A person-named mailbox is never stored.
- Storage: the row budget is 30,000, not the spec's 300,000, because the database is on the 500 MB free plan (owner decision `prospects-row-budget`). A bulk delivery to a prospect dataset is refused (507) while the database is past its storage alert level.
- Batches: a bulk run's deliveries carry the run's start and `merge`; the last one replaces, so what the run did not bring goes. The file store and the database store now follow the same rule.
- Foursquare Open Source Places is not built (first to drop under the spec's cut order).
- Owner steps: Add the source on the card, run GitHub → Actions → Overture Maps collection, then Activate.
- Tests: `apps/data-gateway/test/prospects.test.mjs` (batches, aliases, groups, config), `apps/web/src/server/gateway/prospects.test.ts` (the card's source states), `apps/web/src/app/api/cron/gateway-ingest/route.test.ts` (batch marks, storage guard). The collector was run against release 2026-10-21.0 and its rows searched through a local gateway.

# WJ-798: Keys: tags, notes and follow-up reminders

**What.** Every key on Sources → Keys and Settings → Platform keys has "Add tags or a note". An admin can give a key:
- tags, separated by commas, with tags already in use offered for one-click reuse;
- a short note;
- a "Remind me on" date.

Tags and the note show under the key.

The filter row gains two kinds of chip:
- one chip per tag, to show only keys with that tag;
- "Follow-up due N", which shows only keys whose reminder day has come.

These combine with All / Not set / Set.

**Why.** Owner, 2026-11-07: "allow to add some tags and notes to this for further filtering and reminders". For example: Reddit waiting on API approval, the ReliefWeb appname requested.

**How.**
- `server/jobslake/keyNotes.ts` keeps one small platform-tenant document, `wj.keynotes`. Limits: at most 6 tags of 24 characters each, and a note of up to 500 characters.
- Only known key names are accepted. Each save records who and when, and the audit names the key only.
- Notes are plain text about a key, never a key's value; the editor says so.
- Reminders show on this page only; no email is sent.

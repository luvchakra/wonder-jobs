# WJ-896 · Jobs · DONE

**What:** Level, Places, Minimum salary and Work mode are gone from every profile's form, My profile included. A profile keeps its name, Role you want, Search words, Résumé and Skills, plus Search and Delete. Refine is the one place for level, location, salary and work mode.
- **Per-profile Refine (Full Time):** Refine keeps these four choices for each profile. Picking a profile under Search as brings back its own. A search as a profile uses them. After a reload, Refine shows the choices of the profile whose results are on screen.
- **Moving stored values:** a role's saved level, places, salary or work mode move into its Refine choices once, the first time the role is used. Only values the role set differently from My profile move; a copy taken when the role was made isn't a choice. A level moves into Refine's Level.
- **My profile:**
  - Its search already used Refine's work mode and salary.
  - Its places still start Full Time's Location until places are picked there. Refine shows them, so they're seen and changed in Refine.
- **Scoring and scheduled runs** read Refine's values:
  - **Level:** the level the search's words name, else Refine's Level (the nearest picked), else the level in your Current role. With none of these, no level is preferred ("No level picked in Refine.").
  - **Salary:** Refine's Salary only.
  - A role's stored level, places, salary or work mode are never read for search or scoring. Runs carry Refine's Level in `searchCriteria.levels`.

**Why:** Owner, 2026-11-28: "remove any duplicate search option from profile section of its already present in refine section. it should be removed from all profiles. just keep the minimum parameters which are not part of refine". This reverses part of #807.

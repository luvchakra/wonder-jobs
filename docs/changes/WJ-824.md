# WJ-824 · WorksLake gateway · DONE

**What:** A WonderArk business search can now name two more live sources: Apollo (organisations by keyword, place and size; 1 paid unit a page) and data.gov.in's company register (active Indian companies by registered name or NIC industry code; free). Each is listed on `GET /v1/prospects/sources` and on Prospect data as "Needs setup" until its key is on Admin → Keys (`APOLLO_API_KEY`, `DATA_GOV_IN_API_KEY`), with a Test for each key; every provider now also shows what it costs.
**Why:** Package A3 of `docs/PROSPECT_DATA_API.md` (WonderArk prospect data), left open by WJ-822.
**Notes:** Neither was tried against its real API (no key). Apollo's reference was read on 2026-11-12; its API terms allow internal use only and ask for Apollo's approval before results go to another product, so the owner decision `prospects-apollo` says to leave the key unset until Apollo approves. data.gov.in still refused the build network, so its resource id and fields were taken from open-source clients that call it (recorded as second-hand in `docs/EXTERNAL_DATA_SOURCES.md` §14; decision `prospects-data-gov-in`). Governance: keys stay in the encrypted key store and reach the gateway per request; answers are data (markup removed), never stored, kept in memory 24 hours by default; a failing or slow provider says "unavailable" and the rest of the search is returned. Tests: `apps/data-gateway/test/lookup-providers.test.mjs`, `providers.test.mjs`, `apps/web/src/server/gateway/prospectHooks.test.ts`.

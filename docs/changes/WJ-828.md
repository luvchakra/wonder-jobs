# WJ-828: A network post names a module only when it carries that module's listing

- **What:** A post written from the + no longer gets the module that happened to be open (a "hello all" post read "Therapists"). A post shows a module only when it carries a listing, and then it is the listing's module. Posts already stored without a listing stop showing their module. "New post" now just says "To your network".
- **Why:** Owner question (2026-11-21): "why does it say therapists in the post".
- **Notes:** `server/network/social.ts` (`publishPost` ignores `module` without a listing; `feedFor` drops it from older posts without one). `PostSheet` loses its `module`/`moduleLabel` props. Help updated. Tests: `server/network/social.test.ts`.
- **PR:** see the squash commit.

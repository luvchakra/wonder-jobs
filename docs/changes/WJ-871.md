# WJ-871: Live-site E2E on Mondays only

- **What:**
  - **Nightly E2E:** the part that runs against the live site (`real-account.spec.ts`) now runs on Mondays (IST) only when scheduled. The local and signed-in parts, which run against their own builds, stay nightly. Run workflow still runs any part on any day.
  - **CLAUDE.md:** notes the Monday schedule.
- **Why:** Owner (2026-11-25): "yes reduce the frequency", after the Vercel account was paused for Fluid Active CPU.
- **Notes:**
  - **Reminders stay hourly** (`reminders.yml`): a candidate can ask for a reminder 1 or 3 hours before an interview (Calendar → Remind me), and help promises a check every hour, so a slower schedule would raise those late. The `settings.test.ts` check that the admin's cron list matches the workflow caught this.
  - Source collection (`gateway-collect.yml`, every 3 hours) stays as it is. It runs the collection on the GitHub runner against Supabase, and its runs since the runner secrets were set skip the site-calling fallback, so it uses no Vercel CPU.
  - The other site calls are already infrequent: OSM weekly, Overture twice a month, H-1B monthly, and Vercel's four daily crons.

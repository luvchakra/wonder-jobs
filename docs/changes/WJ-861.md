# WJ-861: A shared listing opens inside the app for members

- **What:**
  - Tapping a listing attached to a network post, or to a community discussion, opened its public share page (`/s/<module>/<id>`). That page asks visitors to sign up even when they are signed in. It now opens `/app/network/listing/<module>/<id>`: the same listing, inside the app (network mode), with a back arrow and **Find it in <module>**.
  - A signed-in member who opens a `/s/…` link directly, from WhatsApp for example, is redirected there too. Signed-out visitors and link-preview crawlers still get the public page.
  - The listing's content (kind, title, facts, details, About, original posting, credit) is now one shared part, `wonderworks/listing/SharedListingView.tsx`, used by both pages.
- **Why:** Owner report (2026-11-23), on a feed post's listing: "on clicking, it takes users to logged out page".
- **Notes:**
  - The in-app page shows only what the public page already shows to anyone, read through the same `sharedListing`. No tenant data is read.
  - `components/network/ListingCard.tsx::inAppListing` maps the link (unit-tested).
  - Help is updated (Network).

# WJ-870 · WorksLake gateway · DONE

**What:** A channel found for WonderArk (a YouTube channel, a Facebook, Instagram or LinkedIn page) now arrives with its enquiry email address when the channel itself published one in its own description or profile text, marked with where it was published. WonderArk saves it as the channel's contact, so a written email can be sent.
**Why:** Owner, 2026-11-23: "the email could be brought in when these channels were searched", after an email draft for an Instagram channel had no address to go to.
**Notes:** Changes the earlier rule that a channel result never carries an email (owner decision `prospects-solo-creators`, updated in `decisions.ts` and `docs/EXTERNAL_DATA_SOURCES.md` §14.1). Only an address read from the channel's own public text: none is looked up, guessed, built from a name or read from another page; no-reply, example and image-file look-alikes are dropped. Podcasts, Reddit communities and stored channel rows carry none. New fields `contactEmail` and `contactEmailSource` on the Channel record (OpenAPI updated); older consumers ignore them. Tests: `publishedEmail`, YouTube and social-search records.

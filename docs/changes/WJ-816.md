# WJ-816 · Storage safeguards · DONE

**What:** The daily storage pass now counts each source's limit per module. A source that also feeds a prospect dataset (the OpenStreetMap services sources since WJ-815) keeps its Talent & Services listings whatever the dataset holds. Rows in a prospect dataset have their own limit, **Prospect rows per source** on Admin → Storage (50,000 by default).
**Why:** Found while building the prospect data API (owner, 2026-11-11, `docs/PROSPECT_DATA_API.md`): WJ-815 stores each OpenStreetMap business twice, once for Talent & Services and once for the businesses dataset. The pass counted both against the one 5,000 limit per source and removed the oldest beyond it, so a source with more than 2,500 businesses could have lost Services listings after its next collection. No collection has run since WJ-815 merged, so nothing was removed.
**Notes:** Governance: none. Storage: unchanged for every existing source. Test: `safeguards.test.ts` (`overCap`).

# WJ-802: Refine choices survive a reload in every module

**What.**
- Find's Refine (its chips such as People / Teams / Posts / New startups, places and sort) is now kept in each module's synced store. A reload, or opening Find again on another device, shows the same choices.
- Clear refinements resets all of them in one write.
- Jobs already kept its own Refine and is unchanged.

**Why.** Owner, 2026-11-07: "once i refresh the page, the selection disappears. ensure all saved refine items are persisted in all modules". The shared `ModuleFind` held Refine only in component state.

**How.**
- `ModuleState.refine` and `setRefine` live in `wonderworks/store.ts`.
- `compactRefine` keeps only set values, capped at 20 keys of 200 characters each, 10 places and a sort.
- Private-search modules keep no Refine, just as they keep no searches.

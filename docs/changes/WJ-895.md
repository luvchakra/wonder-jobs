# WJ-895 · Jobs · DONE

**What:** Find never shows one profile's results under another profile's name. When you pick a different profile under Search as:
- **Switching back to My profile:** if My profile's last results were kept this session, they come back at once.
- **Otherwise:** the list is set aside and says "Press Search to search as <profile>". The summary, the breakdown and the "Searched … for …" line are hidden until you search.
- **Picking the first profile again:** its results show again.

**Why:** Owner, 2026-11-28: "my profile is selected, which is iam related, still it's showing result for reinsurance, fix properly". The role line followed the pick, but the list kept the last run's jobs until Search.

**Notes:**
- `modules/jobs/searchAs.ts::profileSwitch(picked, onScreen, hasProfileCatalog)` decides between "same", "restore_profile" and "press_search". The profile on screen comes from the active or last run's role.
- Find's page restores My profile's kept results with `restoreProfileCatalog()`. JobsBoard's `switchedTo` shows the empty state. After a reload the pick is cleared, so the page shows what's stored with its own name.
- Per-profile stored runs (one catalog for each role) were not added; that was optional.
- Tests: `searchAs.test.ts` covers the switch both ways, with and without a stored catalog, and the case after a reload where the pick and the screen match.
- Checked at 390px in UI 1 and UI 2:
  - searched as Reinsurance (272 jobs, "Searched 14 sources for “reinsurance”");
  - picked My profile → "Press Search to search as My profile", 0 cards, no "Searched" line;
  - picked Reinsurance → its 272 jobs again.
  - No sideways scroll.
- Help: the Search as line says so.
- No automation, AI or external-action change.

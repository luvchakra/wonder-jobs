# WJ-794: Decision rows say what to press

**What.** On Sources → Import, each owner decision now has its own buttons, named for the answer or the thing done, in place of "Mark decided".
- Examples: "Yes, build the reader" / "Not now", "Terms confirmed" / "Keep them paused", "Secrets added".
- One line under the buttons says what each one does. Each button also shows it on hover.
- Pressing a button records which answer was given, plus who and when, and takes the row off the list.
- Links name their destination ("Open Keys", "Open github.com ↗") instead of "Open".

Module cards were renamed as well:
- "Import" is now "Collect <module> now".
- "Set up N" is now "Set up N new sources".
- "Review N" is now "See N that need you".

Each of these has a hover hint.

**Why.** Owner, 2026-11-07: "change the button names to something more descriptive and meaningfull, give hints etc. "mark decided" doesnt tell me what to do".

**How.**
- Answers live in `server/jobslake/decisions.ts::DECISION_ANSWERS`, keyed by decision id. A decision added later without answers gets a plain "Done" until its module adds its own.
- `decisions.test.ts` checks that every decision has one or two answers with hints.
- An answer only records itself, as it did before. Its hint says what follows, for example "ask Claude to build it".

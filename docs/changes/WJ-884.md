# WJ-884 · Jobs · DONE

**What:** A skill typed into **+ Add a skill** is added when the box loses focus, the same as on Enter. This applies to My profile and to every role.
- Commas add several. Each name is trimmed, and blanks and existing skills (any case) are skipped.
- Save changes and a role's Search also save whatever is still in the box, so nothing typed is lost.
- Text in the box counts as an unsaved change.

**Why:** Owner, 2026-11-26 (phone): "after entering a new value, clicking outside should add the new skill". They typed "insurance" in a role's skills, tapped elsewhere, and it stayed as text.

**Notes:**
- One component, `components/career/SkillsInput.tsx`, shows the chips and the add box for every profile (used by `ProfileFields`).
- Helpers in `profileForm.ts`: `addSkills` (commas, trim, case-insensitive dedupe) and `withTypedSkill`. A role whose skills follow My profile's starts from those. Tests are in `profileForm.test.ts`.
- The page keeps each box's text (`typedSkills`), so `saveAll` includes it.
- A role's Search button keeps the box focused on press (`preventDefault` on mousedown). Otherwise the chip added on blur moves the button out from under the tap.
- Other inputs on the page: Places is a comma-separated text field, not chips, so typed text is already kept. Industries are fixed chips.
- Checked at 390px:
  - typing "insurance, Reinsurance" then tapping elsewhere adds two chips and clears the box;
  - typing a skill then pressing Save changes saves it;
  - typing a skill in a new role then pressing Search saves it and opens Find;
  - no sideways scroll.
- No automation, AI or external-action change.

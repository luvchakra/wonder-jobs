# WJ-722 · Platform (shared) · DONE

**What:** A source's Test (and every connector call) now reads the keys set on Admin → Keys first. USAJOBS's Test said "needs credentials on this deployment" in 1 ms, although USAJOBS_API_KEY and USAJOBS_EMAIL were both set there.
**Why:** Owner, 2026-11-05 (screenshot: USAJOBS Test failed, keys set). `runConnector` checked the in-memory key cache without loading it, and a fresh server hadn't read it yet. Searches worked only because they load the keys first.
**Notes:** `loadPlatformKeys` is cached for a minute, so the extra call costs nothing on a warm server. No security change: keys are still decrypted only on the server and never logged.
**PR:** see the PR that adds this file.

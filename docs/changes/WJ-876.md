# WJ-876: A second UI behind a platform switch (step 1: the switch, tokens and shared parts)

- **What:**
  - **The switch.** Admin → Settings → **Look** has "Everyone sees: First UI / Second UI". It also has "This device", which lets an admin try a UI in one browser before switching everyone. The first UI is the default, and switching back is the same press.
    - The choice is kept under the platform tenant (`wj.look`), and only platform admins can change it (audited as `ui.update`).
    - Everyone's pages read it from `/api/ui`, edge-cached for a minute.
    - A browser remembers it and applies it before first paint, so a reload doesn't flash the other UI.
  - **The second UI's tokens** (`:root[data-ui="2"]` in `globals.css`): white surfaces, near-black text, hairline borders, one accent (the brand purple; no gradient, blue or magenta), Inter, 12px cards, 8px buttons, flat cards with shadows only on what floats. Every screen follows them without its own code.
  - **Shared parts** in `src/wonderworks/ui2/`: Header, ChipRow, SectionHeader, CardRail, Sections, the four cards (portrait, info, category tile, feature) and Skeleton. They are presentation only; screens start using them in the next steps.
  - **The bottom bar floats** in the second UI: a translucent pill off the screen's edge, with the same four places and links.
  - **`scripts/ui-shot.mjs`** takes a screenshot of any screen in either UI. `CLAUDE.md` has the rules for keeping two UIs.
- **Why:** Owner (2026-11-28): a visual refresh modelled on a modern discovery app, optional and reversible: "keep a config in platform level to switch to second ui. if i don't like it, i should be able to change to first ui". No functionality changes.
- **Notes:**
  - The first UI is untouched: without `data-ui="2"` none of the new rules apply, and Inter isn't preloaded.
  - Nothing differs between the UIs except look and layout: same routes, fetches, permissions and actions.
  - A switch reaches a user on their next page load after the one-minute edge cache; that page shows the previous UI for a moment the first time.

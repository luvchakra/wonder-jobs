# WJ-813: Network links for modules

- **What:** A shared helper and a shared link so any module can point a person it already shows to their network profile: `server/network/links.ts::networkIdFor` / `networkIdsFor`, and `components/network/parts.tsx::NetworkLink` ("View network profile").
- **Why:** Owner request (2026-11-20): Network should connect with every module as far as possible. Each module session wires it into its own pages.
- **Notes:**
  - **Security:** the helper answers only when both people are on the network, neither blocked the other, and the person is findable by everyone or already stands with the viewer. "Only people with your link" and "Connections only" profiles are never linked from a module page. Only the public id reaches the browser. If the network is unavailable it returns nothing.
  - A module must call it only for a person whose identity that page already shows this viewer.
  - Test: `server/network/network.test.ts` (who gets an id, link-only and connections-only stay hidden, block hides both ways).
- **PR:** see the squash commit.
